Corset.flattenable — Method

Whether syntax node is reduce(vcat, pieces; init = T[]) with T other than Any. When every piece is a vector, collect(T, Iterators.flatten(pieces)) gives the same result in one allocation. A piece that is not one is appended whole by vcat but iterated by flatten, which then fails to convert to T, unless T is Any: the fixer leaves those folds alone.

Corset.abstract_field_plan — Method
abstract_field_plan(repository, directories)

An unsafe fix (unsafe_fix_plan): the rewrite changes the type of the struct, so a use the checked directories do not show (another directory, a downstream package) can break or change silently, and a public constructor changes. The FixPlan that writes the structs of directories with abstract-typed fields as @concrete structs whose such fields read x <: T, imports @concrete into each module and lists ConcreteStructs in the Project.toml [deps]. A struct the macro cannot express, whose field a later write could retype, or that any checked file refers to other than as S(x), ::S or <: S, stays (parameter_fields).

Corset.parameter_fields — Method

The abstract-typed fields of struct syntax node the fixer makes parameters, in order. None when a statement of the body is not a field (x::T or a bare x, which stays bare: the macro makes it an unbounded parameter that the rule still flags), or when a reference to the struct could break or change (usage.escaping). A field of a mutable struct that is written anywhere keeps its type: the parameter would pin the type of the first value built, and a later assignment of another type (a Fill, then a Vector) would throw.
