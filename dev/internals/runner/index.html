Corset.relaunch — Method
relaunch(root, args)

Replace this process with a Julia process whose active project is root, running corset on args. Corset's own environment stays on the load path after the project's, so the project's versions of shared dependencies win, and the default environment (@v#.#) comes last, so a JET installed there runs the jet rule. Where execv does not exist the command runs as a child and its exit code is returned.

Corset.run_command — Method
run_command(args, out, err)

The corset command on the streams out and err. Returns the exit code: 0 when clean, 1 when a finding fails the run, 2 on a usage or configuration error (UsageError, Entries.SourceError, a bad argument or a malformed TOML file), 3 on any other exception, which is Corset's own failure (its error and backtrace go to err). An interrupt is rethrown.
