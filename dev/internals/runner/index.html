Corset.OPT_OUT — Constant

# lint: RULE opts its own line out of RULE, # lint: RULE-begin … # lint: RULE-end the lines between (inclusive), # lint: RULE-file the whole file; the reason follows on the comment. A rule name is lowercase words joined by -.

Corset.run_rules — Method
run_rules(config, root; mod = nothing, signatures = nothing, fix = false, update_baseline = false)

The findings of every rule config leaves on, over the project at root, and the names of the rules skipped because they read the loaded package mod and none was given. The rules that read inferred types also need signatures, the fixed workload inferred_methods types mod over; without them they are skipped. fix first rewrites the files for the rules that have a fixer. update_baseline seeds and lowers the baseline file; without it the baseline is only read.

Corset.relaunch — Method
relaunch(root, args)

Replace this process with a Julia process whose active project is root, running corset on args. Corset's own environment stays on the load path after the project's, so the project's versions of shared dependencies win. Where execv does not exist the command runs as a child and its exit code is returned.
