Array rules

The constant-array, nan-initializer and similar-array rules and their fixers.

Corset.ConstantArrayCall — Type

One call of a Base constant-array constructor: its syntax node, the callee name and the usage of its result.

source
Corset.FillRewrite — Type

The FillArrays constructor that replaces the callee at the bytes range of the file path.

source
Corset.WrittenNames — Type

The field and variable names some code writes through (name[…] = …, name .= …, f!(name)).

source
Corset.array_name — Method

The name of the array syntax node holds: a variable, or the last field of a.b.name; "" for anything else.

source
Corset.call_name — Method

The callee name of call syntax node, with a trailing ! kept; infix calls name their operator.

source
Corset.call_usage — Method

The usage of the array that call syntax call builds: the entry or variable it is bound to, read in its scope, or else the call's own parent. An array that escapes under a field or entry name some code writes through, or a local name some code writes through as a field, counts as written.

source
Corset.callee_name — Method

The last name of callee syntax callee: f for f and Mod.f, "" for anything else.

source
Corset.constant_array_calls — Method

Every call of a Base constant-array constructor under syntax node, with the usage of its result, in source order.

source
Corset.constant_array_plan — Method
constant_array_plan(repository, directories, unsafe)

The FixPlan that writes zeros, ones, fill, trues and falses calls of directories as Zeros, Ones, Fill, Trues and Falses, imports those names from FillArrays into each module and lists FillArrays in the Project.toml [deps]. A call is repaired only when no code writes the array; with unsafe, an array that leaves its function is repaired too, unless a name it is bound to is written elsewhere.

source
Corset.constant_array_repairs — Method

The repairs of the Julia file source: one per constant-array call, the :escape ones too when unsafe.

source
Corset.constant_array_site — Method

The site of the constant-array call in source, at its lines.

source
Corset.constant_array_sites — Method

One constant-array site per call whose result no code writes (constant_array_calls): a written array has no FillArrays form.

source
Corset.constructor_name — Method

The name zeros of callee syntax callee (zeros or Base.zeros), or "" when it is neither.

source
Corset.dependency_file — Method

The Project.toml above the file path, as path => text, with FillArrays added to its [deps]; empty when it lists FillArrays already or no project exists.

source
Corset.enclosing_scope — Method

The nearest function, lambda, let or macro definition around syntax node, as a vector of one node, or of none at the top level.

source
Corset.entry_name — Method

The name an entry name = call (a keyword argument or a named-tuple entry) gives the call syntax call, or "" when call is no such entry.

source
Corset.fill_arrays_names — Method

The names statement, a using or import, brings in from FillArrays: its imported names, or ["*"] for a bare using FillArrays.

source
Corset.fill_value_kind — Method

Whether the value syntax value of a fill is :number (immutable), :mutable (aliased by fill, so left alone) or :unknown.

source
Corset.filled_file — Method

The text of the file path with the callee edits made and the FillArrays names they use imported into the module each sits in.

source
Corset.filled_texts — Method

The new text of each file edits touch, as path => text, with FillArrays added to the Project.toml above each.

source
Corset.import_edit — Method

The edit that imports the FillArrays constructors the import scope of a file text uses but does not import: after its last import, or at its start.

source
Corset.import_scope — Method

The import scope of the byte offset below syntax node: the body of the innermost module around it, else scope, the file.

source
Corset.import_statements — Method

Every using and import statement of the scope node, a file or a module body, outside functions and nested modules, in source order.

source

source

source
Corset.in_view_macro — Method

Whether node is a direct argument of its call parent parent, not the callee.

Whether syntax node is assigned to: the target of an assignment, alone or inside a destructuring tuple.

Corset.is_prefix_call — Method

Whether call syntax node is the prefix call f(…), not an infix, postfix or dotted call.

source

Whether index is a scalar operand or a sum or difference of two.

source

Whether syntax node is an integer literal or end: a name may hold a vector, so it is no scalar.

source

Whether assignment binding is a statement that discards its value: a block child that is not a function's result.

Corset.names_no_variable — Method

Corset.names_type — Method

Whether syntax argument names a type: a capitalized name, a parametric type, or typeof(…), eltype(…), promote_type(…).

Corset.project_deps — Method

source
Corset.reads_only — Method

Whether the call syntax call of the function name returns a scalar: a reader of the list, without keywords such as dims, and first/last without a count.

source
Corset.scalar_index — Method

Whether every index of reference, a ref node, is an integer literal, end or a sum of them: the read gives an element, not a slice.

How the array that syntax node holds (the call itself, or an occurrence of the name it is bound to) is used, judged by its parent.

Corset.variable_usage — Method

source
Corset.written_in — Method

source
Corset.written_names — Method

The names below syntax node that some code writes through, as :field => name or :variable => name.

Corset.NanInitializer — Type

Corset.binding_initializers — Method

The NanInitializer of the assignment binding of a constant-array call to a variable, as a vector that is empty when the array is never written, only accumulated, or its element type is unknown.

source
Corset.constructor_rank — Method

The number of dimensions the constructor dimensions texts give, or 0 when a tuple, a size(…) or a splat hides it.

source
Corset.covers_dimension — Method

Whether range syntax range runs over the whole of dimension dimension of the array name of dimensions dimensions.

source
Corset.element_and_dimensions — Method

The element type text and dimension texts of the call syntax call of zeros, ones or fill, as (type, dimensions) with type == "" for Float64, or UNTYPED_FILL as the type when a fill value has an unknown type.

source
Corset.from_first_reader — Method

The statements from the first one that reads the variable name on, empty when none does.

source
Corset.has_exit — Method

Whether the syntax node holds an early exit of its loop: break, continue, return.

source
Corset.initializes_array — Method

Whether the statement later writes the array name in full before any read: name .= …, or a loop over every index whose first statement to use name is name[i, …] = ….

source
Corset.is_accumulation — Method

Whether the read of an array is the target of an accumulation x[i] += …, x .+= … or x += …: it reads its start value.

source

The FixPlan that rewrites each proven initializer zeros(T, dims…), ones(T, dims…) or fill(v, dims…) as fill(T(NaN), dims…).

source

The repairs of source: one per proven initializer.

source
Corset.nan_initializer_site — Method

The site of initializer in source, at its lines.

source
Corset.nan_initializer_sites — Method

One site per written array initialized with a constant (nan_initializers).

source
Corset.nan_initializers — Method

Every written constant-array initializer below syntax node, in source order.

source
Corset.nan_text — Method

The text of the NaN initializer that replaces initializer: fill(T(NaN), dimensions…), or fill(NaN, dimensions…) for Float64; fill!(similar(x, T, dims), NaN) when the dimensions are length(x) or size(x) of a parameter annotated as an array.

source
Corset.writes_every_index — Method

Whether the assignment write is name[i, …] = … with the loop variables of ranges as its indices, each ranging over the whole of its dimension.

source
Corset.ArrayConstruction — Type

One construction of a concrete array: its syntax node, the form (:undef for C{T}(undef, dims…), :conversion for C(x); the empty growable forms T[] and C{T}() have no template to mirror and are not constructions), the element type text and, for :undef, the template variable and extent call it is sized by.

source

Corset.array_constructions — Method

source
Corset.container_of — Method

The container name and element type text of constructor callee head (Vector{T} gives ("Vector", "T"), Matrix gives ("Matrix", "")), or an empty name when it is no container.

source
