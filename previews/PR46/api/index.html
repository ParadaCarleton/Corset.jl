API

Corset.Corset — Module

Code-quality rules checked on a loaded module and on its repository's Julia source. A rule is a function returning the Sites it finds; ratchet! fails a test on them. By default every site fails; a Repository given a baseline file holds each rule to its per-rule counts there instead, failing on new offenders and lowering the counts when offenders go away. The caller picks the rules, the module and source files they read, and their limits.

Corset.Repository — Type
Repository(root; baseline = nothing, one_letter_exempt = (), skipped_directories = ())

The tree the rules read, and the settings that relax them. The defaults are the strict reading: every finding of every rule fails. root is the tree whose source the rules read (made absolute).

  • baseline: the TOML file of per-rule allowances that ratchet! holds findings to; nothing allows none. It may be a link: ratchet! resolves it at each call, so a lowering lands in the file it points to.
  • one_letter_exempt: the variable names the one-letter rule allows besides _ (a project's own convention, such as an argument everywhere named p).
  • skipped_directories: directory names repository_sources leaves out wherever they sit, such as ("vendor",). Hidden directories (a leading .) are always left out.

Corset.float64_ops — Method
float64_ops(f, types)

Number of Float64 operations in the fully optimized IR of f(::types...).

A wrapper number type observes a Float64 only when it is promoted with, or converted from, a wrapped number, so a dependency that computes internally at Float64 and narrows before returning is invisible to it — the expensive silent case, where the caller pays Float64 arithmetic and keeps Float32 storage. The IR sees that widening whichever package caused it, without forking or instrumenting the dependency.

Heuristic, not a proof: it reads the IR optimize=true produced for one concrete signature, so a Float64 reached only through runtime dispatch is out of scope, and a non-inlined callee is visible through its call signature rather than its body. Use == 0 on kernels that must stay narrow, and keep the positive controls so a change to the filter cannot quietly disarm the check.

Corset.offenders! — Method
offenders!(repository, rule, sites; scopes = ("",), fix = "")

The keys of rule's offenders sites that repository does not allow, logged. Sites that a # lint: comment naming the rule opts out are dropped and counted in the log; the rest are tallied by key. Without a baseline (Repository's default) every key is returned. With one, the offenders are held to rule's table in the baseline file: the keys past their entry are returned, and an entry the tally undercuts is lowered or deleted and the file rewritten. A rule with no table is seeded with its tally. Several testsets may share one rule's table, and a run may not measure all of it (a partial copy of the tree): each passes the prefixes scopes that begin the keys it measures, and only entries under one of them can fall. fix tells the reader of the log how to repair an offender, such as the forms the rule accepts.

Corset.undefined_names — Method
undefined_names(path; scope)

Scan one test file for names its testsets use but nothing defines.

A name counts as defined when any binding of it appears anywhere in the file or its literal includes (every scope, including modules and other testsets): the scan over-approximates, so a reported name has no definition in reach.

Returns (unresolved, unlowered). unresolved holds one "line N:name" entry per undefined name. unlowered names the testsets whose macros could not be expanded here, which the scan therefore did not cover: report it, because a scan that quietly skips a testset reads exactly like one that cleared it.

scope is the module the testsets run in, which owns the macros the bodies use and the names they resolve against. Pass @__MODULE__.
