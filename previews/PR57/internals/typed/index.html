Typed-code rules

Rules that read inferred code: the entry walk, mutation, dispatch, JET, Float64 operations and non-public access.

Corset.entry_frames — Method
entry_frames(seeds, target)

The typed_frames of every signature reachable from seeds (entry-point call signatures such as Tuple{typeof(f), Int}) along frame_callees edges, the seeds included; empty where inference yields none. Pass them to inferred_methods, which then infers nothing again.

source
Corset.followed — Method

Whether a walk of target follows callee, an invoked_instance: a method of target, or one whose signature names a type of it.

source
Corset.frame_callees — Method
frame_callees(ir, target)

The signatures ir, an optimized method body, calls through :invoke edges and a walk of target follows: callees defined in target or whose signature names one of its types (JET's target_modules scope).

source
Corset.invoked_instance — Method
invoked_instance(callee)

The method instance an :invoke statement names: a CodeInstance on Julia 1.12 and later.

source

mentions_module(signature, target, depth)

Whether signature names a type defined in target anywhere in its parameters.

source
Corset.new_callees — Method

The signatures the frontier frames call that frames does not hold yet.

source
Corset.signature_callees — Method

The signatures the frames of signature call (frame_callees).

Corset.ArgumentWrites — Type

What a frame or statement does to arguments, as indices: those it writes through, those it passes to a runtime dispatch, and those it passes to a ccall. The analysis cannot read the last two callees.

source
Corset.alias_indices — Method

The indices escape analysis puts in one alias set with index, index included.

source
Corset.argument_writes — Method
argument_writes(frame, frames, stack)

The ArgumentWrites of frame, as argument numbers; a written argument is neither dispatched nor foreign. A statically resolved callee writes the arguments its own frame in frames (keyed by method instance) writes; a callee named with ! writes its first argument; any other callee writes none. stack holds the instances being summarized, which a recursive call skips.

source
Corset.called_builtin — Method

The builtin or intrinsic a :call statement calls; nothing for a generic function.

source
Corset.declared_io — Method

Whether method declares argument index as an abstract IO (io::IO, io::T where T <: IO): it writes whatever stream its caller passes, an OS handle included, so a specialization's IOBuffer does not count.

source
Corset.effect_arguments — Method

The arguments that the field operands of the statement effects reach (reached_arguments).

source
Corset.escape_state — Method

The escape analysis of ir, a method body of nargs arguments, in the current world.

source
Corset.invoked_writes — Method

Corset.mutation_sites — Method

Corset.operand_index — Method

The escape-analysis index of IR operand operand; nothing for a constant or a global.

source
Corset.operand_indices — Method

The indices of the IR operands operands that escape analysis tracks.

source
Corset.os_context — Method

Whether type is an IOContext around an os_handle.

source
Corset.os_handle — Method

Whether every value of type type is an OS-backed handle: an OS_HANDLES type or a libuv stream other than the in-memory BufferStream.

source
Corset.reached_arguments — Method

The arguments (2 and up; 1 is the function itself) whose memory the values at indices may point into: their escape-analysis aliases, closed under the memory a MEMORY_VIEWS result views.

source
Corset.statement_writes — Method

The ArgumentWrites of one IR statement, as the indices of its operands.

source
Corset.unmarked_mutations — Method

Each is_unmarked_method among inferred whose frame writes through one of its arguments, one site per method: "writes argument x", or "may write" when the argument reaches a runtime dispatch (which runtime-dispatch also reports) or a ccall, whose code the analysis does not read. A writing method added to another module's function (Base.length, Base.iterate) breaks what that function's callers expect.

source
Corset.view_sources — Method

The aliases of the memory that SSA index index views when its statement is a MEMORY_VIEWS call; none otherwise.

source
Corset.writable — Method

Whether a write through a value of type type changes a Julia object: not plain_capture data, a type or a module, and not an os_handle, whose writes reach the file system or the OS.

source
Corset.writable_operands — Method

The indices of the operands whose IR type is writable. A call cannot write a Symbol or a bits value (a Ptr too, which C reads by value) it is passed.

source
Corset.written_detail — Method

The detail of a site where method writes its argument name, naming the owner of a function another module owns.

source
Corset.audited_frames — Method

The inferred frames whose method is in repository's own files and whose first line carries no # lint: rule opt-out, which so covers the whole method.

source
Corset.compiled_concretely — Method
compiled_concretely(return_type)

Whether a caller compiles against return_type: concrete, Union{} (always throws), a Type{X} constant, a union of at most UNION_SPLIT_LIMIT concrete members, which Julia splits, or a fixed-length tuple whose members each compile concretely.

source
Corset.dispatch_sites — Method

The runtime_dispatches sites of item, one per dispatching statement, placed at its line in the method.

source
Corset.dispatches — Method

Whether statement of ir dispatches at run time: a :call of a generic function, or of a builtin that calls one (CALLING_BUILTINS). A logging hand-off (logging_call) dispatches by design.

source
Corset.logging_argument — Method

Whether a call argument names Base.CoreLogging or its handle_message.

source
Corset.logging_call — Method
logging_call(statement)

Whether a :call statement is a logging macro's hand-off to the current logger, which is an AbstractLogger chosen at runtime and so always dispatches.

source
Corset.opted_out — Method

Whether the first line of item's method is among the opted-out lines skipped holds for its file.

source
Corset.runtime_dispatches — Method
runtime_dispatches(repository, inferred)

Each call the compiler leaves to run-time dispatch (dispatches) in a frame of inferred that audited_frames keeps, one site per method and source line.

source
Corset.widened_returns — Method
widened_returns(repository, inferred)

Each method of inferred (as audited_frames keeps them) whose inferred result does not compile concretely (compiled_concretely), one site at its first line however many specializations ran.

Corset.non_public_accesses — Function
non_public_accesses(mod, file = entry_file(mod))

Each name of another module that mod reaches by qualified access (Base.JuliaSyntax) or explicit import (using Base: uniontypes) though that module neither exports it nor declares it public. ExplicitImports reads file and the files it includes. A qualified access has a site per use; an explicit import has one per name, at its first import.

source
Corset.non_public_site — Method

The site of the ExplicitImports finding row, a name of the module owner, keyed Owner.name.

source
Corset.qualified_uses — Method

Every qualified use in submodule, from the ExplicitImports file analysis, of a non-public name that findings (ExplicitImports rows, one per name) report.
