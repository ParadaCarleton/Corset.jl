Typed-code rules

Rules that read inferred code: the entry walk, runtime-dispatch candidates, mutation, dispatch, float widening, JET, Float64 operations and non-public access.

Corset.entry_frames — Method
entry_frames(seeds, target)

The typed_frames of every signature reachable from seeds (entry-point call signatures such as Tuple{typeof(f), Int}) along frame_callees edges, the seeds included; empty where inference yields none. Pass them to inferred_methods, which then infers nothing again.

Corset.DEFAULT_CANDIDATE_LIMIT — Constant

The candidate_limit a search uses unless told otherwise: the most methods one runtime-dispatch site lists.

Corset.CandidateSearch — Type

A candidate search: at most limit methods per runtime-dispatch call (0 lists none), and every frame inferred so far by method instance, nothing where inference failed. Searches that share frames infer no frame twice.

source
Corset.CandidateSearch — Method
CandidateSearch(inferred; candidate_limit = DEFAULT_CANDIDATE_LIMIT)

A search seeded with the rules' own inferred frames. A negative candidate_limit throws.

Corset.Candidates — Type

The methods a runtime-dispatch call may reach, each inferred over its intersection with the call's signature. complete is false when the budget ran out, the call has no plain signature (a splat, a Core.invoke), or inference failed on a candidate; frames then holds the candidates it did type.

Corset.ArgumentWrites — Type

What a frame or statement does to arguments, as indices: those it writes through, those it passes to a runtime dispatch it cannot resolve, and those it passes to a ccall. The analysis cannot read the last two callees. writers pairs a written index with the runtime-dispatch candidate that writes it.

source
Corset.alias_indices — Method

The indices escape analysis puts in one alias set with index, index included.

source
Corset.argument_writes — Method
argument_writes(frame, frames, stack, search)

The ArgumentWrites of frame, as argument numbers; a written argument is neither dispatched nor foreign. A statically resolved callee writes the arguments its own frame in frames (keyed by method instance) writes; a callee named with ! writes its first argument; any other callee writes none. A runtime dispatch writes what its call_candidates in search write (dispatch_writes). stack holds the instances being summarized, which a recursive call skips.

Corset.declared_io — Method

Corset.dispatch_writes — Method

Corset.unmarked_mutations — Method
unmarked_mutations(repository, inferred; search = CandidateSearch(inferred))

Each is_unmarked_method among inferred whose frame writes through one of its arguments, one site per method: "writes argument x", or "may write" when the argument reaches a ccall or a runtime dispatch whose call_candidates in search are incomplete. runtime-dispatch reports the dispatch itself. A write by a runtime-dispatch candidate names the candidate. A writing method added to another module's function (Base.length, Base.iterate) breaks what its callers expect.

source
Corset.unresolved_positions — Method

The positions whose argument candidate frame passes on to a dispatch or a ccall (effect).

source
Corset.view_sources — Method

source
Corset.writable — Method

Whether a write through a value of type type changes a Julia object: not plain_capture data, a type or a module, and not an os_handle, whose writes reach the file system or the OS.

source
Corset.writable_operands — Method

The indices of the operands whose IR type is writable. A call cannot write a Symbol or a bits value (a Ptr too, which C reads by value) it is passed.

source
Corset.writable_positions — Method

The positions (2 and up) of operands, a call's arguments with its callee first, whose IR type is writable.

compiled_concretely(return_type)

Whether a caller compiles against return_type: concrete, Union{} (always throws), a Type{X} constant, a union of at most UNION_SPLIT_LIMIT concrete members, which Julia splits, or a fixed-length tuple whose members each compile concretely.

widened_returns(repository, inferred)

Corset.carries_floats — Method

source
Corset.dispatch_widening — Method

The detail of runtime-dispatch statement of ir under budget: a candidate whose result holds a wider float makes it definite; an incomplete list makes it "may widen". A dispatch whose operand types hold none of the floats budget receives is skipped (nothing).

source
Corset.float_budget — Method

The FloatBudget of item, from its argument types.

source
Corset.float_widenings — Method
float_widenings(repository, inferred; search = CandidateSearch(inferred))

Each statement of an audited frame (audited_frames) whose float result is wider than every float its method receives in its arguments (x::Float32 * 2.0, float(n) in a Float32 method), one site per method and line. A frame with no float argument, or one as wide as Float64, is skipped. A runtime dispatch is judged by its call_candidates in search (dispatch_widening).

source
Corset.frame_widenings — Method

The float_widenings sites of item, one per widening statement.

source
Corset.held_floats — Method

The concrete float types type holds: itself, or any type parameter at depth below 5 (Vector{Float32}, Complex{Float64}, Tuple{Int, Float16}), each union member included.

source
Corset.ir_label — Method

Corset.judged — Method

Corset.result_floats — Method

Corset.non_public_accesses — Function
non_public_accesses(mod, file = entry_file(mod))

Each name of another module that mod reaches by qualified access (Base.JuliaSyntax) or explicit import (using Base: uniontypes) though that module neither exports it nor declares it public. ExplicitImports reads file and the files it includes. A qualified access has a site per use; an explicit import has one per name, at its first import.

Entry signatures

Corset.Entries finds the concrete call signatures a walk starts from. It reads only a Module, paths and types.

Corset.Entries — Module

Entry signatures of a loaded module: concrete call signatures such as Tuple{typeof(f), Int} that a type-inference walk can start from. Each source is one function of a Module and paths; entry_signatures takes the union of the sources it names.

source
Corset.Entries.SOURCES — Constant

The sources source_signatures and entry_signatures accept.

source
Corset.Entries.binding_methods — Method

The methods of binding value when it is a kind: a function's methods, or a type's constructors.

source
Corset.Entries.call_methods — Method

The methods that call an instance of binding value when it is a struct type; none otherwise.

source
Corset.Entries.compiled_signatures — Method
compiled_signatures(mod)

The concrete signatures the running process has specialized mod's methods on: those a package image's precompile workload compiled, and those compiled since loading.

source
Corset.Entries.configured_signatures — Method
configured_signatures(path, name)

The signatures the function name of the file path returns. The file is included in a fresh module; the function takes no arguments and returns a vector of signature types. Any other result throws.

source
Corset.Entries.declared_signatures — Method
declared_signatures(mod)

The signatures of mod's methods whose declared argument types are all concrete already.

source
Corset.Entries.defined_methods — Method
defined_methods(mod)

The methods mod defines on its own functions and types, closures included: each function's methods, and each type's constructors and call methods.

ponytail: methods mod adds to another module's function (Base.show, AD rules) are missed; Base.visit over the method table finds those but misses closure call methods on Julia 1.13 and needs a mutating callback.

source
Corset.Entries.defines — Method

Whether signature is a concrete call signature that selects a method mod defines.

source
Corset.Entries.entry_signatures — Method
entry_signatures(mod; sources = (:compiled, :declared), root = nothing, output = devnull, unset = ())

The union of the source_signatures of mod from each of sources, each signature once.

source
Corset.Entries.module_bindings — Method

The values bound to the names of mod, unexported and compiler-made names included.

source
Corset.Entries.source_signatures — Method
source_signatures(mod, source; root = nothing, output = devnull, unset = ())

The entry signatures of mod from one of SOURCES: :compiled (compiled_signatures), :declared (declared_signatures) or :tests (the trace_signatures of the package at root's test_trace, its test output written to output, the variables unset removed from its environment).

source
Corset.Entries.test_trace — Method
test_trace(root, output; unset = ())

Run the tests of the package at root (Pkg.test) in a child process started with --trace-compile, writing its output to output, and return the trace file's path. The child inherits every environment variable except those named in unset. A failing test run throws.

source
Corset.Entries.trace_scope — Method

A module that binds every loaded package by name, and mod, so a trace line's qualified type names resolve.

source
Corset.Entries.trace_signatures — Method
trace_signatures(mod, trace)

The signatures in the precompile(Tuple{...}) lines of the --trace-compile file trace that select a method mod defines. A line whose type does not evaluate in this process (a type the test files define) is dropped.

source
Corset.Entries.traced_type — Method

The type of the trace line line, precompile(Tuple{...}), evaluated in scope; nothing for any other line or one that fails to evaluate.
