Rules that read parsed source files, and the rule registry.

An opt-out on a method's first line covers all its locals (audited_frames, under comments).

Corset.names_concrete_type — Function
names_concrete_type(annotation, scope, variables = ())

Whether parsed type expression annotation names a concrete type of scope or of Base (Float32, Vector{E}, a package struct), alone or as a member of a Union. A result type must be generic (typeof(x), a type variable, AbstractVector{E}), so a fixed concrete type is named here, except Nothing, Bool, tuples and NamedTuples (EXEMPT_RESULT_TYPES) and enum types. A type variable, typeof(x) and an abstract type name none. A package struct with a parameter that mentions one of the method's where variables (Result{E}, Result{Vector{E}}) is generic too: it has no abstract form to name instead. Base's own concrete types stay concrete with such a parameter, since AbstractVector{E} names Vector{E}'s.
