Typed-code rules

Rules that read inferred code: the entry walk, runtime-dispatch candidates, mutation, dispatch, float widening, JET, Float64 operations and non-public access.

Corset.cut_off — Method

Whether optimized statement statement invokes a method instance inference cut off at its recursion limit: an :invoke whose callee has a concrete signature but no CodeInstance, since inference kept no code for it.

source
Corset.cut_off_instances — Method

The method instances ir, an optimized method body, invokes that inference cut off (cut_off). Each nests its argument types deeper than its caller's, so a walk that followed one, or any other instance of its method, would infer a new instance at every step and never finish.

source
Corset.cut_off_methods — Method

The methods of the cut_off_instances of ir.

Corset.entry_frames — Method
entry_frames(seeds, target)

The Inferred frame of every method instance of target's package (belongs) reachable from seeds (entry-point call signatures such as Tuple{typeof(f), Int}) along frame_callees edges, the seeds included. Each instance is inferred once; frames of other modules are walked through and dropped.

source
Corset.followed — Method

Whether a walk of package follows callee, an invoked_instance: a method of package, or one whose signature names a type of it.

source
Corset.frame_callees — Method
frame_callees(ir, package)

The method instances ir, an optimized method body, calls that a walk of package follows: the :invoke edges defined in package or with a signature naming one of its types (JET's target_modules scope), and the inlined callees defined in package. Another module's inlined callee needs no frame: its own calls are already in ir. No instance of a method that ir calls past inference's recursion limit (cut_off_instances) is followed, so the walk ends.

Corset.ArgumentWrites — Type

What a frame or statement does to arguments, as indices: those it writes through, those it passes to a runtime dispatch it cannot resolve, and those it passes to a ccall. The analysis cannot read the last two callees. writers pairs a written index with the runtime-dispatch candidate that writes it. cut is set when a recursive call was skipped, so the summary depends on the instances being summarized.

source
Corset.WriteWalk — Type

The frames a write summary follows, keyed by method instance, and the summaries already made, keyed by method instance and candidate limit. A summary that skipped a recursive call (cut) is not kept.

source
Corset.alias_indices — Method

Corset.argument_writes — Method
argument_writes(frame, walk, stack, search)

The ArgumentWrites of frame, as argument numbers; a written argument is neither dispatched nor foreign. A statically resolved callee writes the arguments its own frame in walk writes; a callee named with ! writes its first argument; any other callee writes none. A runtime dispatch writes what its call_candidates in search write (dispatch_writes). stack holds the instances being summarized, which a recursive call skips. A summary is made once per instance and search limit.

source

Corset.unmarked_mutations — Method
unmarked_mutations(repository, inferred; search = CandidateSearch(inferred))

Each is_unmarked_method among inferred whose frame writes through one of its arguments, one site per method: "writes argument x", or "may write" when the argument reaches a ccall or a runtime dispatch whose call_candidates in search are incomplete. runtime-dispatch reports the dispatch itself. A write by a runtime-dispatch candidate names the candidate. A writing method added to another module's function (Base.length, Base.iterate) breaks what its callers expect.

Corset.recursion_limits — Method
recursion_limits(repository, inferred, mod; comments = Dict())

One site per call in the inferred frames (as audited_frames keeps them under comments) that inference cut off at its recursion limit (cut_off), to a method of mod's package. The callee's argument types nest deeper with every call (grow((x,), n - 1)), so it is inferred and compiled anew at each depth and never optimized with its caller. JET's optimization analysis reports the frames past the cut as OptimizationFailureReport.

source

Corset.float_widenings — Method
float_widenings(repository, inferred; search = CandidateSearch(inferred), comments = Dict())

Each statement of an audited frame (audited_frames under comments) whose float result is wider than every float its method receives in its arguments (x::Float32 * 2.0, float(n) in a Float32 method), one site per method and line. Corset.call_report_sites — Method
call_report_sites(repository, inferred, mod; comments = Dict())

Entry signatures

Corset.Entries finds the concrete call signatures a walk starts from. It reads only a Module, paths, types and Corset.Membership.

Corset.Entries — Module

Entry signatures of a loaded module: concrete call signatures such as Tuple{typeof(f), Int} that a type-inference walk can start from. Each source is one function of a Module and paths; entry_signatures takes the union of the sources it names.

source
Corset.Entries.SOURCES — Constant

The sources source_signatures and entry_signatures accept.

source
Corset.Entries.SourceError — Type

A source that cannot give signatures through no fault of this module: failing tests, or a bad configured_signatures file.

source
Corset.Entries.binding_methods — Method

The methods of binding value when it is a kind: a function's methods, or a type's constructors.

source
Corset.Entries.call_methods — Method

The methods that call an instance of binding value when it is a struct type; none otherwise.

source

compiled_signatures(mod; own_methods = defined_methods(mod))

configured_signatures(path, name)

Corset.Entries.loaded_functions — Method

Every function bound in Base, Core or a loaded module: where a package may add methods.

source
Corset.Entries.source_signatures — Method
source_signatures(mod, source; root = nothing, output = devnull, unset = (), own_methods = defined_methods(mod))

The entry signatures of mod from one of SOURCES: :compiled (compiled_signatures), :declared (declared_signatures), both read from mod's methods own_methods, or :tests (the trace_signatures of the package at root's test_trace, its test output written to output, the variables unset removed from its environment).
